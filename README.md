# SpamZap
Stay Safe Online!!

## About
Detect and flag spam messages instantly across different social media apps, Also check URLs without you clicking on it.

## Usage
1) Load the extension
2) Run the extension

## Handler Usage
run server.py file to open server for detecting spam msgs based on the dataset trained.

## Note
Don't forgot to add your opengraph and google safe browsing api key.
